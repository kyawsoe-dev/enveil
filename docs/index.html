What ENVEIL Handles

One desktop app for the secret-heavy parts of daily development: vault storage, project env files, local command running, diffing, history, and LAN sharing.

Encrypted Vault

Master password based Argon2id key derivation with ChaCha20Poly1305 encrypted storage.

Project Env Editing

Create projects, bulk import keys, drag in .env files, export values, and generate .env.example.

Temp .env Linking

Create secure temporary .env files and link them into project folders for local tooling.

Terminal Runner

Run saved commands with decrypted variables injected only into the child process.

Diff and History

Compare projects, compare against .env files, and restore automatic env snapshots.

LAN Sync

Share selected projects with teammates on the same network using per-project share passwords.

Screenshots

The app is built for repeated work: dense project views, quick search, clear diffs, and direct controls.

Security Model

ENVEIL is designed for local-first secret handling. Secrets are decrypted only after vault unlock and are never written to your global environment.

  • Argon2id derives a 32-byte key from the master password.
  • ChaCha20Poly1305 provides authenticated encryption for the vault payload.
  • The encrypted vault file is stored in the operating system config directory.
  • Auto-lock can clean up temporary env files and stop running child processes.
  • LAN project sharing is protected with per-project share passwords.

Development

ENVEIL uses Tauri v1 for the Rust desktop shell and Next.js 14 for the frontend.

Install frontend dependencies

Install the Next.js dependencies inside the desktop app folder.

cd desktop
npm install

Run the desktop app

The Tauri dev command starts the Next.js dev server and opens the desktop window.

cargo tauri dev

Build release bundles

The frontend exports statically to desktop/out/, which Tauri loads in the webview.

cargo tauri build
