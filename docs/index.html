    What ENVEIL Handles

    One desktop app for the secret-heavy parts of daily development: vault storage, project env files, local command running, diffing, history, and LAN sharing.

    Encrypted Vault

    Master password based Argon2id key derivation with ChaCha20Poly1305 encrypted storage.

    Project Env Editing

    Create projects, bulk import keys, drag in .env files, export values, and generate .env.example.

    Temp .env Linking

    Create secure temporary .env files and link them into project folders for local tooling.

    Terminal Runner

    Run saved commands with decrypted variables injected only into the child process.

    Diff and History

    Compare projects, compare against .env files, and restore automatic env snapshots.

    LAN Sync

    Share selected projects with teammates on the same network using per-project share passwords.

    Security Model

    ENVEIL is designed for local-first secret handling. Secrets are decrypted only after vault unlock and are never written to your global environment.

    Argon2id Key Derivation

    Derives a 32-byte encryption key from the master password using memory-hard Argon2id.

    ChaCha20Poly1305 Encryption

    Authenticated encryption for the vault payload, ensuring confidentiality and integrity.

    Secure Local Storage

    The encrypted vault file is stored in the OS config directory, never written to global environment.

    Auto-Lock Protection

    Auto-lock cleans up temporary env files and stops running child processes to prevent leaks.

    Per-Project Share Passwords

    LAN project sharing is protected with per-project share passwords for secure team collaboration.

    Master Password Authentication

    Every vault unlock requires the master password — secrets are never accessible without it.

    Secure Import & Export

    Import and export vault data through encrypted channels, never exposing plaintext secrets.

    Audit & Visibility Controls

    Full visibility into which projects and env vars have been accessed, exported, or shared.

    Development

    ENVEIL uses Tauri v1 for the Rust desktop shell and Next.js 14 for the frontend.

    Install frontend dependencies

    Install the Next.js dependencies inside the desktop app folder. 

    cd desktop & npm install

    Run the desktop app

    The Tauri dev command starts the Next.js dev server and opens the desktop window. 

    cargo tauri dev

    Build release bundles

    The frontend exports statically to desktop/out/, which Tauri loads in the webview. 

    cargo tauri build
